**Research snapshot:** 2026-10-19. Accession/metadata checks used NCBI SRA/BioProject and E-utilities; publications were checked in full text where available. No read files were downloaded and no pipeline was run. “Verified archive record” means accession and basic metadata were observable; it does not certify every file can later be fetched, every label, or benchmark approval.

## Negative and confounder interpretation

- **Proposed within-study negative:** the paper's Px31 statement (no satRNA-associated reads and no expected-size PCR product) is promising, but only after exact SRA run and helper status are linked. Until then, it is not a verified TN.
- **Ordinary viral variation:** grapevine/Phlox virome samples contain multiple viral taxa and distinct isolates. Useful as sequence-similarity and mixed-infection challenges, not automatically clean satellite negatives. A proper negative needs independent satellite testing, ideally with cognate helper present and adequate quality/depth.
- **DVGs:** PRJNA525871 is a positive DVG challenge, not a negative control for every satellite-like candidate. DVGs, ordinary variation, recombination, and satellite RNAs require separate strata.
- **Unavailable:** no run-linked, validated satellite-negative library was fully verified in this review. No human-associated satellite dataset is proposed for the starter benchmark.

## Evidence status vocabulary

- **Verified archive record:** accession/basic metadata observable; not proof every file/checksum was retrieved.
- **Verified publication finding:** paper reports result/method; not an exact SRA run label unless that map was checked.
- **Proposed candidate:** useful lead with at least one necessary link, ground truth, or compatibility check unresolved.
- **Unavailable:** no eligible run identified with evidence in this review; not a biological negative.
- **Unevaluable:** future case cannot be scored because reads, labels, provenance, or technical requirements are inadequate. Keep outside negative denominators.
