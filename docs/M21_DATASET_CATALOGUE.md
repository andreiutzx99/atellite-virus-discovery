**Run-map evidence:** NCBI SRA E-utilities search for BioProject PRJNA1244124 returns nine records. Per-record SRA summaries give the Experiment names, Experiment accessions, BioSample accessions, and Run accessions above. The article identifies the same three biological sample names and states raw reads were deposited under PRJNA1244124. The crosswalk is high-confidence for these three runs. Do not infer identities for the other six records from accession ordering; they have distinct Experiment/sample titles and require independent study/label adjudication.

**Minimal feasibility set:** after read availability/checksum, data-use terms, and technical adequacy are confirmed, use only these three named plant libraries (two satellite-positive samples and one target-specific screen-negative/helper-positive sample), each from a distinct biological plant in this one study. This can assess within-study feasibility only. It cannot estimate general sensitivity or specificity, and the negative assay's unknown detection limit must be disclosed. Keep the separate uninfected RT-PCR control out of read-based denominators because no corresponding SRA library is identified.

## Negative and confounder interpretation

- **Px31 is not an absolute-absence label.** It is a named sample with no target-associated reads and no expected-size target-specific RT-PCR product reported. State that the result is limited by unknown assay and sequencing sensitivity; use a sample-level negative only if a review panel accepts this evidence and read adequacy is confirmed.
- **Helper status is separately evidenced.** The paper reports BRSV in Px15, PxBG2, and Px31 by HTS and virus-specific RT-PCR; detected amplicon sequence confirmation is reported. This supports a helper-positive control designation, but does not itself prove a biological dependence relationship.
- **Other BioProject records:** the project query currently returns nine public SRA records, including six additional Phlox sample records beyond Px15/PxBG2/Px31. They are not presumed satellite-positive or negative from shared project membership; check publication/source provenance and orthogonal test results individually.
- **Ordinary viral variation:** grapevine/Phlox virome samples contain multiple viral taxa and distinct isolates. Useful as sequence-similarity and mixed-infection challenges, not automatically clean satellite negatives. A proper negative needs independent target testing, ideally with cognate helper present and adequate quality/depth.
- **DVGs:** PRJNA525871 is a positive DVG challenge, not a negative control for every satellite-like candidate. DVGs, ordinary variation, recombination, and satellite RNAs require separate strata.
- **Unavailable:** no additional independent-study, helper-positive satellite-negative read sample with sufficiently documented target-specific orthogonal validation was verified here. No human-associated satellite dataset is proposed for the starter benchmark.

## Evaluation definitions for any later feasibility review

- Define one binary call per independently verified, evaluable biological sample before unblinding. Sample-level specificity is TN/(TN+FP) only over that defined satellite-negative sample set; a sample with multiple false candidate calls is still one sample-level FP.
- Report false candidate calls as counts per negative biological sample and per million input reads or read pairs, with each numerator and denominator shown. Do not call FP/(FP+TN) a candidate-level false-positive rate because there is no defined candidate-negative universe.
- Candidate-level precision and recall require frozen candidate deduplication and one-to-one matching rules, with explicit finite truth targets. Report matched/total counts and uncertainty; candidate recall is limited to the curated truth set.
- Report sample-level uncertainty (e.g. exact binomial intervals) and count-rate uncertainty, grouping technical duplicates and related samples by biological source. Unevaluable cases are counted by reason and excluded from all metric denominators.
- One Phlox study with two positives and one target-specific screen-negative plant is a feasibility case only, not a broad sensitivity/specificity estimate; leave-study-out/independent-study validation remains required.
