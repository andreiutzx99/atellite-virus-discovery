# M19 follow-up scope

The initial deterministic quantitative matrix is documented in
[M19_SYNTHETIC_BENCHMARK.md](M19_SYNTHETIC_BENCHMARK.md). Possible follow-ups
remain separate from its current conclusions:

1. Add independently seeded replicates and wider factor ranges while keeping
   truth outside every analysis input.
2. Evaluate more read layouts and assembler versions under fixed resource
   limits, with explicit blocked/unavailable states.
3. Add synthetic-only reference snapshots for exercising M8 handoffs without
   biological curation or classification claims.
4. Extend interrupted-run and cache-identity tests without changing M1–M18
   contracts or M4 provenance rules.
